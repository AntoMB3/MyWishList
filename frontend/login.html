Términos y privacidad

Información sobre el uso de MyWishList.

Términos del servicio

1. El servicio

MyWishList permite crear y organizar listas de deseos y compartirlas mediante un enlace. El servicio se ofrece tal como está y puede cambiar, interrumpirse o dejar de estar disponible. No se garantiza que los precios, la disponibilidad o la información de los productos enlazados estén actualizados.

2. Cuenta y uso responsable

Para crear una cuenta solo se necesita un nombre de usuario y una contraseña; no pedimos el nombre real ni datos de contacto. Eres responsable de mantener la contraseña segura, de la actividad realizada con tu cuenta y de que el contenido que añadas sea lícito y no infrinja derechos de otras personas.

3. Listas compartidas y contenido

Quien tenga el enlace de una lista compartida puede ver su contenido y el nombre de usuario de quien la creó. No incluyas información confidencial o que no quieras hacer pública. Conservas los derechos sobre el contenido que aportas y autorizas su almacenamiento y visualización únicamente para prestar las funciones de la aplicación, incluida la compartición que decidas activar.

4. Enlaces y recursos externos

Los enlaces a tiendas y las imágenes pueden pertenecer a terceros. No controlamos sus contenidos, precios, disponibilidad ni prácticas de privacidad. Al abrir un enlace o cargar una imagen alojada externamente, el navegador puede comunicarse con ese sitio y transmitirle información técnica, como la dirección IP.

5. Seguridad y cambios

Aplicamos medidas técnicas para proteger las cuentas, pero ningún servicio puede garantizar seguridad o disponibilidad absolutas. Podemos actualizar estos términos; la versión vigente se mostrará en esta ventana. Si no estás de acuerdo, deja de usar el servicio.

Política de privacidad

1. Datos que tratamos

No solicitamos ni guardamos tu nombre real, correo electrónico, teléfono ni domicilio. Para que funcione el servicio se guardan:

  • El nombre de usuario y la contraseña en forma de hash; la contraseña no se conserva en texto legible.
  • Las listas y los datos que añadas, como títulos, descripciones, precios y enlaces o direcciones de imágenes.
  • Identificadores internos y fechas de creación necesarios para gestionar las cuentas y el contenido.

2. Para qué se utilizan

Estos datos se usan para autenticarte, guardar y mostrar tus listas, permitir que las gestiones y publicar las listas que decidas compartir. La versión actual de la aplicación no integra herramientas propias de analítica, publicidad ni venta de datos.

3. Sesión y almacenamiento

Al iniciar sesión, el navegador guarda un token de acceso para mantener la sesión: en el almacenamiento local si eliges «Recordarme» o en el almacenamiento de sesión si no. El token contiene un identificador interno y su caducidad; no es una cookie. Puedes cerrar la sesión para eliminarlo del navegador.

4. Compartición y servicios de terceros

Las listas compartidas son accesibles para cualquiera que tenga su enlace y muestran el nombre de usuario asociado. Además, al cargar imágenes alojadas en otros sitios o abrir enlaces externos, esos proveedores pueden recibir información técnica de tu navegador y aplicar sus propias políticas de privacidad.

5. Conservación y control

Las listas y sus artículos permanecen guardados hasta que los elimines o se elimine la cuenta o la base de datos que los contiene. Actualmente no existe una opción para borrar la cuenta desde la aplicación; la eliminación de una cuenta requiere intervención de quien administra esta instancia.

6. Infraestructura

El servidor o proveedor de alojamiento puede procesar registros técnicos necesarios para operar y proteger el servicio. La información y el tiempo de conservación de esos registros dependen de la configuración y las condiciones del alojamiento, que no se detallan en la aplicación.
